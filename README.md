# Postman Magic

Automatyczny eksport publicznej dokumentacji Postman Documenter do OpenAPI 3.1 oraz gotowej dokumentacji Scalar.

Źródło domyślne: https://documenter.getpostman.com/view/3616447/SVn2PvjX

Uruchamianie: **Actions → Postman Documenter → OpenAPI + Scalar → Run workflow**.

Workflow zapisuje wynik jako artifact `postman-magic-output`, zawierający m.in. `openapi.yaml`, `openapi.json`, `index.html`, raport ekstrakcji i diagnostykę.
